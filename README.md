# 🎮 GameZone Retro

## 📋 Sobre o Projeto

O **GameZone Retro** é uma página web promocional desenvolvida em **HTML** para representar uma loja especializada em jogos e consoles clássicos.

O projeto foi desenvolvido como parte de um **Mini Desafio HTML**, com o objetivo de colocar em prática conceitos básicos de HTML, como títulos, parágrafos, listas, links, imagens e tabelas.

## 🎯 Objetivo

Criar uma página simples, organizada e funcional para apresentar uma loja de games retrô, respeitando o limite de **50 linhas de código HTML**.

## 🛠️ Tecnologias Utilizadas

* **HTML5**
* HTML puro, sem frameworks ou bibliotecas externas
* Imagem em formato JPG

## 🎮 Funcionalidades

A página possui:

* Título com o nome da loja;
* Texto de apresentação utilizando **negrito** e *itálico*;
* Link interno para a seção de produtos;
* Link externo para um site relacionado a games;
* Imagem relacionada ao tema retrô;
* Lista de consoles disponíveis;
* Tabela com jogos, consoles e preços.

## 🕹️ Consoles Disponíveis

* Nintendo (NES)
* Super Nintendo (SNES)
* Saga Genesis

## 📁 Estrutura do Projeto

```text
GameZone-Retro/
├── desafio.html
└── assets/
    └── retro.jpg
```

O arquivo `desafio.html` contém toda a estrutura da página, enquanto a pasta `assets` armazena a imagem utilizada no projeto.

## 🚀 Como Executar

1. Baixe ou clone o projeto.
2. Mantenha o arquivo `desafio.html` e a pasta `assets` no mesmo projeto.
3. Abra o arquivo `desafio.html` em um navegador.
4. Teste os links e confira a exibição da imagem e da tabela.
